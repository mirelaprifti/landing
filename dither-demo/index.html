Hero Section Dithering Options

Current (No Dithering)

The current smooth radial glow for reference.

Option 1: Bayer/Ordered (8×8)

Classic halftone pattern. Technical/retro aesthetic. Creates structured, grid-like transitions.

Option 2: Stipple/Dots

Random dot pattern. More organic, modern texture feel.

Option 3: Line/Hatching

Diagonal lines. Engraved/blueprint aesthetic.

Option 4: Subtle Glow Dithering

Keeps smooth center, adds dithered texture to outer glow. Minimal change.

Bonus: Large Bayer (16×16)

Larger pattern for a bolder, more visible effect.

Bonus: Crosshatch

Intersecting diagonal lines. Technical/engineering look.
