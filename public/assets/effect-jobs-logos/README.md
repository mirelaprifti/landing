# Effect Jobs — Company Logos

Drop company logos here as SVG (preferred) or PNG.

Naming convention: lowercase, kebab-case, matching the company slug used in `src/data/effect-jobs.ts`.

Examples:
- `acemate.svg`
- `vercel.svg`
- `masterclass.svg`

Then reference in the data file:

```ts
{
  company: "Acemate",
  logo: "/assets/effect-jobs-logos/acemate.svg",
  // …
}
```
