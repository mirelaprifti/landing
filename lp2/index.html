The TypeScript Library for Production

Why Effect?

Because your TypeScript deserves better than scattered try-catches, dependency chaos, and mystery crashes at 3am.

Effect gives you typed errors, built-in dependency injection, structured concurrency, and observability — all in one library.

Common Problems Effect Solves

You've felt these pains. Here's how Effect fixes them.

Try-catch blocks everywhere

Your error handling is scattered across the codebase. Runtime crashes happen in production because errors slip through untracked.

Typed Errors

Every possible error is tracked in the type system. The compiler tells you what can fail and forces you to handle it.

Dependency injection chaos

Passing dependencies through constructors, using global singletons, or wrestling with DI frameworks that require decorators and reflection.

Built-in DI

Services are declared as types and provided at the edge. No decorators, no reflection, no magic — just types.

Promise nightmares

Race conditions, unhandled rejections, and no way to cancel operations. Debugging async code feels like guessing.

Structured Concurrency

Fibers with automatic cleanup, cancellation propagation, and proper resource management. Async code that actually makes sense.

Untestable code

Mocking requires patching modules, tests are brittle, and integration tests are slow because everything is tightly coupled.

Testable by Design

Swap implementations at test time without mocking libraries. Your code is naturally decoupled and easy to test.

Zero observability

When production breaks, you're grepping logs hoping to find something useful. No tracing, no metrics, no context.

Built-in Tracing

OpenTelemetry-compatible tracing out of the box. See exactly what happened, with full context, without adding instrumentation code.

Everything You Need

One library. Complete toolkit.

Stop installing a new package for every problem. Effect includes everything you need to build production-grade TypeScript applications.

Error Handling

  • Typed errors in the function signature
  • Short-circuit and collect errors
  • Automatic retry with backoff
  • Timeout and interruption

Concurrency

  • Structured concurrency with fibers
  • Parallel execution with limits
  • Race conditions handled correctly
  • Automatic resource cleanup

Dependency Injection

  • Type-safe service definitions
  • Automatic dependency resolution
  • Easy mocking for tests
  • No decorators or reflection

Observability

  • Built-in OpenTelemetry tracing
  • Structured logging
  • Metrics collection
  • Span context propagation

Schema & Validation

  • Runtime validation from types
  • Automatic JSON serialization
  • API contract generation
  • Form validation support

Scheduling

  • Cron-like schedules
  • Exponential backoff
  • Jittered retries
  • Repeat with conditions

LLMs 🤍 Effect

Write better code with AI

Effect's declarative patterns and rich type information make it ideal for AI-assisted development. LLMs understand Effect code better and produce more reliable results.

Predictable structure

Every operation follows a declarative pattern — no guesswork for LLMs.

Typed feedback loop

Detailed error traces show what failed, enabling precise self-repair.

Built-in reliability

Error handling, supervision, and recovery — production-ready by default.

Rich toolbox

Schema validation to workflows in a language LLMs easily understand.
